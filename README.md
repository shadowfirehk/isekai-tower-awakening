# 異界炮台：命運覺醒

日系異界塔防 RPG。完成永久職業覺醒、炮台養成、地球區域進度，以及 25 波戰鬥挑戰。

## 遊玩

- [目前公開版本](https://isekai-tower-awakening.hyacinthmorrisonmwd.chatgpt.site/)
- GitHub Pages 會在 `main` 分支更新後自動建置並發布。

遊戲進度保存在玩家目前使用的瀏覽器中。

## 本機執行

需要 Node.js 22 或更新版本，以及 pnpm 11。

```bash
pnpm install
pnpm dev
```

正式建置：

```bash
pnpm build
```

- TypeScript
- Vinext / Vite
